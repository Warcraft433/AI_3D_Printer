# Contributing to AI-Integrated 3D Printer

Thank you for your interest in contributing to the AI-Integrated 3D Printer project! We welcome all contributions, from bug fixes to new features.

## How to Contribute

### 1. Report Bugs
If you find a bug, please open an issue on GitHub. Include:
- A clear description of the bug.
- Steps to reproduce.
- Your environment details (OS, Python version, etc.).

### 2. Suggest Features
We love new ideas! Open an issue with the label "enhancement" to discuss your proposal.

### 3. Pull Requests
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/awesome-feature`).
3. Make your changes.
4. Ensure tests pass.
5. Commit your changes (`git commit -m 'Add awesome feature'`).
6. Push to your branch (`git push origin feature/awesome-feature`).
7. Open a Pull Request.

## Coding Standards
- Follow PEP 8 for Python code.
- Use ESLint for React/JS code.
- Write clear, commented code.
- Include unit tests for new logic.
